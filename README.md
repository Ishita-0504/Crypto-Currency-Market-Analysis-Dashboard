# Crypto-Currency-Market-Analysis-Dashboard

## Project Overview
This project focuses on cryptocurrency market analysis using Microsoft Excel dashboards and Python-based web scraping techniques. Real-time cryptocurrency data was collected from CoinMarketCap and transformed into interactive dashboards for visualization and analytical insights.

## Features
* Interactive Excel Dashboards
* Pivot Tables & Pivot Charts
* KPI Cards
* Dynamic Slicers
* Crypto Coin Comparison
* Liquidity Analysis
* Historical Price Analysis
* Investment Insights Dashboard
* Python Web Scraping using BeautifulSoup & Pandas

## Tools & Technologies Used
* Microsoft Excel
* Python
* Pandas
* BeautifulSoup
* Requests
* CoinMarketCap Dataset

## Dashboard Tasks
1. Main Crypto Market Dashboard
2. Crypto Coin Comparison Dashboard
3. Top 5 Crypto Liquidity Analysis
4. Price Change Comparison Analysis
5. Historical Price Change Insights
6. Low Budget Investment Insights
